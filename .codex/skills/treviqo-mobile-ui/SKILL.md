# Treviqo Mobile UI

Read `/docs/ui/UI_UX.md`, `/docs/product/PRODUCT.md`, and `/AGENTS.md`.

Design smartphone layouts first.

Primary mobile navigation:
- Home
- Exit
- Passport
- Documents
- Profile

Prefer cards, step flows, bottom sheets, drawers, expandable details, and sticky mobile actions.

Avoid desktop-first tables and enterprise HR-dashboard patterns.

Every core screen needs loading, empty, error, success, and appropriate processing states.

Desktop should expand the same information architecture.
