# Treviqo Core

Read `/AGENTS.md`, `/docs/product/PRODUCT.md`, `/docs/architecture/ARCHITECTURE.md`, and `/docs/milestones/MILESTONES.md` before major implementation work.

Rules:
- Treviqo is worker-owned employment and benefits continuity, not employer HR software.
- Keep the hackathon MVP focused.
- Use Rumpty Cloud wherever it provides the needed infrastructure capability.
- Design mobile-first and preserve future React Native/Expo compatibility.
- AI extracts evidence; deterministic application logic makes readiness decisions.
- Do not introduce major dependencies or infrastructure providers without explicit approval.
- Run relevant lint, typecheck, tests, and build checks before declaring completion.
